Chain check

Honest limits

  • Everything drawn here comes from the unbroken, verified prefix of the chain, with the same check and pins as the Lab view. After the first break the drawing freezes; unverified or later envelopes never move or colour anything.
  • Each chiplet's top face is one colour: its centre temperature, on one fixed scale for the run. It is not a thermal field, and nothing is interpolated across a die. Side faces are the same colour, shaded only for depth. A run whose data has no centre temperatures draws its chiplets uncoloured: J is its measurement's value and is never spread over the chiplets as if it were one of theirs.
  • The stack is schematic. Substrate, interposer, die heights and the lid are drawing constants. Only the chiplet footprints come from the evidence.
  • A glide is display only: chiplets move from the layout the package showed before (a lab's previous candidate, else the initial layout) to the new candidate. Status (proposed, accepted, stale) comes only from the evidence contract's project().
  • A verified envelope proves the core's key signed it. It does not prove a temperature is physically right.
  • The bundled demo is an interface fixture with illustrative numbers. No solver produced them.
  • TEST KEYS mode uses keys anyone can derive, so only a local server honours it.
