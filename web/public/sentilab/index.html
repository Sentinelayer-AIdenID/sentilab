Honest limits

  • Status shows only what the evidence contract's project() returns over the unbroken, verified prefix of the chain. After the first break the board freezes; later envelopes are listed but never projected.
  • A verified envelope proves the core's key signed it. It does not prove a measurement is physically right.
  • The production key pin is empty until the core's key exists, so nothing verifies on this site yet. TEST KEYS mode uses keys anyone can derive.
  • Colors are chiplet-center temperatures: one number per chiplet. They are not a continuous thermal field.
  • The bundled demo is an interface fixture with illustrative numbers. No solver produced them.
  • The live feed depends on the core's /api/view routes, which are not served yet. A server that withholds its newest envelopes shows as STALE; the page can see silence, not withholding.
