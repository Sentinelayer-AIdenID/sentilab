## Architecture qualifications

1. **One authoritative scientific writer is useful, not a concurrency proof.** The core can own board mutation and scientific event admission while retaining signed source proposals and denied-operation audit records. Bind append, board change, budget/idempotency state and recoverable artifact references with explicit crash semantics; merely calling the API a core does not establish these guarantees.
2. **Known old parent is not invalid physics.** Preserve draft-0.5's exact-parent delta materialization and current-comparison-board CAS. Unknown/unmaterializable parents, changed contracts or revoked authority can block use; an evaluated valid loser remains `non_improving_current`/`not_selected_current_best` or `within_margin`. Warden explicitly accepted this correction in his latest reply. Positive admission margins still require the frozen sequential-versus-batch ordering decision.
3. **Senti tickets are a queue candidate, not proven infrastructure integration.** Verify actual claim exclusivity, lease TTL/renewal, fencing after lease loss, duplicate delivery, atomic evidence submission, artifact persistence/ACL, retry/poison policy and orphan recovery. A reported 15-minute renewal procedure is not that proof. Keep scientific admission independent of mutable ticket status. Use the existing queue if the approved integration demonstrates these properties; do not build a replacement without evidence of a missing requirement.
4. **Shared renderer does not prove live/replay equivalence.** Live transport can omit, reorder, duplicate or delay events, reconnect at a wrong cursor or present partial artifacts. Replay may use a different initial state or time reduction. Test ordered IDs/cursors, gaps, resume, deduplication, event-schema versions, snapshot boundaries and equivalent settled state as well as intended timing/labels. SSE is optional; correct bounded polling can satisfy the same contract.
5. **Accepted-only memory would erase useful science.** Keep valid negative experiments, failed hypotheses, schema/geometry corrections, rejected proposals and reproduced non-winners with distinct outcome/evidence status. Only eligible authorized evidence enters retrieval/training; invalid or withdrawn claims are not silently recycled as truth. Preserve arm/family/seed isolation and lab subnamespaces, shared-arm policy, raw audit history, source rights and every-input training taint. “Accepted board winner” is not equivalent to “valid evidence.”
