**Search state.** Simulated annealing sometimes explores a worse intermediate state. Its exploration state must be separate from the accepted best design, whose checks remain strict.

A signed event history provides useful integrity evidence, but the starter’s local signing demonstration still needs actual platform integration. Likewise, an append-only record and its retained checkpoints need a clear verification procedure.

### Moment three: another team gets useful work done

Make **Senti ResultCheck** the smallest useful cross-team service.

A partner submits paired measurements with sample IDs, metric names, units, and the intended comparison. The checker returns the arithmetic, consistency flags, and an inspectable receipt. It should identify insufficient data rather than manufacture statistical confidence.

Its scope is **submitted-data consistency and arithmetic**. It does not certify the authenticity of the measurements or the physical validity of the other team’s model.

The collaboration evidence should be:

**Real partner request → executed check → returned receipt → observed downstream use.**

Recruit that partner early. A documented API alone does not establish that another team benefited.
