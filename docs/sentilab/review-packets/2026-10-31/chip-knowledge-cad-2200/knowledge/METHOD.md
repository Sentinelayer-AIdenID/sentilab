`build-cards.cjs` reads the sources, verifies their expected hashes where a prior seal was supplied, and writes one JSON object per line to `knowledge.jsonl`. Each quotation carries the exact original absolute/relative source path, full-file SHA256 and one-based line locator. A few full-line quotes normalize CRLF to LF for readability and explicitly mark that normalization; original file hashes cover untouched bytes. Other quotations are exact substrings, not paraphrases. `SOURCE-BINDINGS.json` lists the ten source files, byte counts and SHA256 values. Sources are referenced in place, not modified or silently copied into a new apparent original.

The frozen diagnosis must retain SHA256 `132bf28fc6d962ae159a942084b3a7fe4c17fd52dc65da7a13789939a0460a7d` and 68,772 bytes. Both generation and final verification require that identity. Later qualified retained-field evidence is not used to rewrite the old report or claim that missing v3 raw inputs have appeared.

Reported values are transcribed from the existing sources. Only display rounding to the retained 0.01 K precision is applied to the eight field rows; floating-point display tails are not extra physical precision. The CPU estimate remains an existing proportional forecast rather than a new timing result. The geometry card preserves the historical reconstruction/snapping comparison; its null legalized-layout result describes this card's cited evidence, not a claim that later geometry artifacts do not exist.

Each card separates claim, conditions, evidence kind, objective/metric, comparator/intervention, reported effect, uncertainty/missingness, independent-verification scope, architectural usefulness and transfer limits. Unknown hardware characteristics, physical accuracy, effect confidence intervals and unmeasured causal improvements are explicit nulls. Software resource accounting is distinguished from simulated temperatures and from physical chip measurements. The wire card explicitly uses different comparators for its wire change and thermal screen; it does not conflate the 1.595 C screen gap with a measured gain over the initial layout.

Prior verification is attributed narrowly. The retained stack report checked 112 file hashes over eight existing datasets; the separate parser checked 28 hashes and the complete grids for two baseline datasets only, without rehashing the solver binary. Geometry findings are a prior independent extraction of displayed PDF vectors, not manufacturer CAD. This curator rechecks report identities and quotations; it does not claim to have repeated those underlying analyses or launched fresh reproductions.

`verify-and-seal.cjs` checks the ten source hashes, every quote locator, card schema/identities, the frozen report, and direct transcription invariants. It writes `VERIFICATION.json` and `SEAL.json`. These are artifact-integrity checks, not scientific acceptance tests. No outcome is upgraded to PASS by this packet, and no job grant or spending authorization is created.
