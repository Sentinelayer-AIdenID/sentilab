## Answers

- InstancedMesh: `constructor( geometry, material, count )`. `instanceMatrix` is an `InstancedBufferAttribute( new Float32Array( count * 16 ), 16 )`. `instanceColor` defaults to `null` and is created lazily by the first `setColorAt`. `setMatrixAt( index, matrix )` writes into `instanceMatrix.array` at `index * 16`. `setColorAt( index, color )` writes into `instanceColor.array` at `index * 3`. The JSDoc says to set the attribute's `needsUpdate` flag after updating. `raycast()` sets `intersect.instanceId = instanceId` on each hit, and `Raycaster~Intersection` documents `instanceId` (S1, S2).
- DataTexture: `constructor( data = null, width = 1, height = 1, format, type, mapping, wrapS, wrapT, magFilter = NearestFilter, minFilter = NearestFilter, anisotropy, colorSpace )`. JSDoc defaults: format=RGBAFormat, type=UnsignedByteType. It overrides `generateMipmaps=false`, `flipY=false` and `unpackAlignment=1`. `needsUpdate` is the Texture setter: when set to `true` it does `this.version ++; this.source.needsUpdate = true;`. `updateRanges` / `addUpdateRange( start, count )` allow partial updates (S3, S4).
- Clipping: `Material.clippingPlanes` defaults to `null`. Its JSDoc says "This requires {@link WebGLRenderer#localClippingEnabled} to be `true`." There are also `clipIntersection` and `clipShadows` (both `false`). `WebGLRenderer.localClippingEnabled` defaults to `false`, and the global `WebGLRenderer.clippingPlanes` defaults to `[]` (S5, S6).
- CSS2DRenderer / CSS2DObject: all styling is done by CSSOM property assignment (`element.style.position`, `.userSelect`, `.overflow`, `.width`, `.height`, `.display`, `.transformOrigin`, `.transform`, `.zIndex`). The only `setAttribute` call is `setAttribute( 'draggable', false )`. There is no `innerHTML`, no `cssText`, no `setAttribute('style', ...)` and no `<style>` element (S8; zero-hit counts are in web-02).
- `renderer.info.render`: `{ frame, calls, triangles, points, lines }`. Each draw does `render.calls ++`; for `gl.TRIANGLES` it does `render.triangles += instanceCount * ( count / 3 )`. `reset()` zeroes calls, triangles, points and lines. `info.autoReset` defaults to `true` (S6, S7).
- `setAnimationLoop( callback )` stores the callback, forwards it to `xr.setAnimationLoop`, and starts the internal `WebGLAnimation`; passing `null` stops it. JSDoc: "Applications are advised to always define the animation loop with this method and not manually with `requestAnimationFrame()`" (S6).
- `dispose()` removes the three context listeners and disposes internal caches. It does not call `loseContext`. `forceContextLoss()` calls `WEBGL_lose_context.loseContext()` if the extension is available (S6).
- Context loss: listeners for `webglcontextlost`, `webglcontextrestored` and `webglcontextcreationerror` are registered before the context is created. `onContextLost` calls `event.preventDefault()`, logs, and sets `_isContextLost = true`. `render()` returns early while it is lost. `onContextRestore` re-runs `initGLContext()` and restores some `info` and `shadowMap` settings (S6).
